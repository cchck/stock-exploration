# 给导师：先看这里

用 CSMAR 复现三篇 A 股论文：LSY（2019）、Allen 等（2024）、Li 等（2024），并把样本延长到 2026 年。

## 阅读顺序

1. **`复现报告.docx`**：只看这一份就够了。第 0 节「结论一页」是摘要；目录可以点击跳转。
2. `对照表/`：报告里每个通过率背后的逐项明细，想核对具体数字时再看。
3. `图/`：报告中 5 张图的原图（报告里已经嵌入，这里给高清版本）。

## 对照表怎么读

每个文件对应一篇论文：`lsy_comparison.csv`、`allen_comparison.csv`、`li_comparison.csv`。每一行是论文里印出来的一个数字，列的含义如下：

| 列 | 含义 |
|---|---|
| `table` / `row` / `col` | 数字在论文中的位置（表号、行、列） |
| `source` | 出处（如 Table 3、正文第几节） |
| `paper` | 论文的数值 |
| `ours` | 我们复现的数值 |
| `diff` | `ours − paper` |
| `kind` | 数字类型，决定用哪条容差。主要几类：`pct_return` 月均收益（±0.10 个百分点）、`t` t 值（落在同一显著性档）、`share_pct` 比例（±3 个百分点）、`count` 计数（±3%）、`rel10` 连续型描述统计（±10%）、`pct_annual` 年化收益（±1.2 个百分点）；`info` 只列出、不打分 |
| `pass` | `True` 在容差内，`False` 超出容差，空白表示不打分（多为只列出的 `info` 行，少数是论文印为 0.00、无法判断符号的系数） |
| `deviation` | 未通过时的偏差编号（如 `LSY-7`、`LI-7`）。主要几条在报告第 2.2 / 3.2 / 4.2 节解释，全部条目在项目的 `docs/deviation_log.md` |

通过率 = `pass` 为 `True` 的行数 ÷ 打分的行数：LSY 699 / 836，Allen 150 / 257，Li 2,510 / 4,270。
